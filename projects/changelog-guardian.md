# Changelog Guardian

- **Dates:** 2021 → present
- **Status:** Active, open source
- **Stack:** Go, DDD
- **Code:** [gitlab.com/aoterocom/changelog-guardian](https://gitlab.com/aoterocom/changelog-guardian)

A tool that automates versioning and releasing, whatever technology an artifact is built with. It follows [Semantic Versioning](https://semver.org/) and keeps a changelog in the [Keep a Changelog](https://keepachangelog.com/) format.

It reads versions from several sources, from GitHub releases and git tags to artifact repositories, and changes from Jira, GitHub pull requests or plain commits.

It grew out of what I learnt owning Changelog Drafter at INDITEX, and today it versions and writes the changelogs of Maiteego's product repositories.
