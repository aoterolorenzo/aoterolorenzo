# Changelog Guardian

- **Dates:** 2021 → actualidad
- **Status:** Activo, open source
- **Stack:** Go, DDD
- **Code:** [gitlab.com/aoterocom/changelog-guardian](https://gitlab.com/aoterocom/changelog-guardian)

Una herramienta que automatiza el versionado y las releases, sea cual sea la tecnología con la que se construya un artefacto. Sigue [Semantic Versioning](https://semver.org/) y mantiene un changelog en formato [Keep a Changelog](https://keepachangelog.com/).

Lee las versiones de varias fuentes, desde releases de GitHub y tags de git hasta repositorios de artefactos, y los cambios desde Jira, pull requests de GitHub o commits sin más.

Nació de lo que aprendí siendo responsable de Changelog Drafter en INDITEX, y hoy versiona y escribe los changelogs de los repositorios de producto de Maiteego.
