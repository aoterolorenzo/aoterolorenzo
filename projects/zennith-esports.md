# Zennith Esports

- **Dates:** 2020 → 2022
- **Status:** Private
- **Stack:** Angular, PHP, Python, MongoDB, Go

![Zennith Esports](../img/zennithesports.jpeg)

Web and desktop software for Zennith Esports, a Spanish sim racing team, joining in-game real-time data with web services.

- A Python desktop client on every driver's computer detects the simulator and streams live data, so the team's broadcast shows live timing straight from the drivers.
- Events run on their own: the system goes live with the event data and the Twitch or YouTube stream.
- A community manager bot generates the event poster as an image and posts it on the morning of the event and at the start.
- Driver profiles sync with the simulators' APIs, and the team shares car setups automatically.
- Angular frontend, PHP API with MongoDB, synced with Nextcloud auth and calendars.
